# Sigilith v1.0 Reproducibility Package

This directory contains all materials required for:

- Peer review
- Independent replication attempts
- Stability testing
- Benchmark comparison

## Contents

| Directory / File | Purpose |
|---|---|
| `benchmark-set/` | Sequences and structural units for replication |
| `rubric/scoring-rubric.md` | Scoring rubric for structural evaluation |
| `evaluator-key/evaluator-key.md` | Expected outputs for comparison |
| `analyst-instructions/instructions.md` | Step-by-step instructions for replicators |
| `blinded-tests/` | Optional blinded batches for stability testing |

## How to Use This Package

1. Read `analyst-instructions/instructions.md` first.
2. Select one or more sequences from `benchmark-set/`.
3. Score each sequence using `rubric/scoring-rubric.md`.
4. Compare your results to `evaluator-key/evaluator-key.md`.
5. Optionally, complete a blinded batch from `blinded-tests/` before consulting the key.
6. Report matches, divergences, ambiguities, and reproducibility issues as a GitHub issue or attached document.

## Scope

This package covers **structural analysis only** — no decipherment, no linguistic claims, no semantic interpretation.
