# Reproducibility

This directory contains all materials needed to reproduce and evaluate the structural analysis presented in *A Reproducible Structural Analysis of the Voynich Manuscript via Sigilith v1.0*.

## Contents

| Directory | Description |
|---|---|
| `benchmark-set/` | Reference benchmark data used for evaluation |
| `rubric/` | Scoring rubric for evaluating outputs |
| `evaluator-key/` | Answer key and guidance for evaluators |
| `analyst-instructions/` | Instructions for independent analysts |
| `blinded-tests/` | Blinded test materials |
