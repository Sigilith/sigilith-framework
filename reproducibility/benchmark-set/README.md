# Benchmark Set — Sigilith v1.0

**Version:** 1.0  
**Framework DOI:** <https://doi.org/10.17613/dkgpg-xbj95>

---

## Overview

This directory contains the canonical benchmark sequences used for replication of the Sigilith v1.0 structural analysis. Each sequence is provided as a plain-text file with a corresponding metadata block.

Sequences are drawn from the following source documents:

- Voynich Manuscript (Yale, Beinecke MS 408)
- Rohonc Codex
- McCormick Notes
- Phaistos Disc
- Liber Linteus
- Turin Papyrus

## How to Use

1. Open each sequence file in order.
2. Use the raw sequence string and the segmentation hints to work through the procedure in `analyst-instructions/instructions.md`.
3. Do **not** consult `evaluator-key/evaluator-key.md` until you have recorded your own scores.

---

## Scope

All sequences are provided for **structural analysis only**. No linguistic, semantic, or decipherment claims are made or implied by the selection of these sequences.
